### 2. 제거 대상

절제 방향에서 가장 큰 소음원 3가지:

- **배경 그리드** (`.bg-grid`) — CSS에서 `display: none`. 규칙을 통째로 지우는 대신
  숨김 처리해, 되돌리기 쉽고 `index.html`을 건드리지 않는다.
- **배경 글로우** (`.bg-glow`) — 동일하게 `display: none`
- **UI 그라데이션** — 히어로 이름(`.typed`), 버튼(`.btn-primary`), 브랜드 마크
  (`.brand-mark`), 섹션 구분선 등을 단색으로 대체

### 2-1. 프로젝트 썸네일 색 — 예외 처리

`.thumb-violet` / `.thumb-blue` / `.thumb-cyan` 3종은 **단색 회색으로 바꾸지 않는다.**

이유: `js/data.js`가 프로젝트마다 `accent: "violet"|"blue"|"cyan"`을 지정하고, 그 값이
썸네일 배경 클래스(`main.js:176`, `258`, `259`)와 **SVG 일러스트 내부 색상 양쪽**에
동시에 쓰인다(`data.js:138` 주석: "accent별 색상은 thumb-* 와 통일"). 배경만 회색으로
바꾸면 SVG 일러스트와 배경이 따로 논다.

**대신 3종의 채도를 낮춰 잉크 블루 계열의 명도 변주로 재구성한다** — 서로 구분은 되되
전체 톤에서 튀지 않는 수준으로. 클래스 이름(`violet`/`blue`/`cyan`)은 `data.js`가
참조하므로 **그대로 두고 색값만 교체**한다. `data.js`는 수정하지 않는다.

SVG 내부 색과의 조화는 브라우저 검증 시 프로젝트 모달을 열어 직접 확인한다.

### 3. 타이포그래피

**Space Grotesk를 UI에서 제거하고 Inter로 통일한다.**

```css
--font-sans: "Inter", system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
--font-display: var(--font-sans);  /* Space Grotesk → Inter */
```

`--font-display` 변수 자체는 **유지한다** — `style.css` 21곳이 참조 중이라 변수만 바꾸면
전체가 한 번에 전환된다.

> **주의**: Google Fonts 링크에서 Space Grotesk를 **지우면 안 된다.** `js/data.js`의
> 프로젝트 SVG 일러스트 12곳이 `font-family="Space Grotesk"`를 하드코딩하고 있어,
> 링크를 제거하면 해당 SVG 서체가 조용히 깨진다. 링크는 유지하고 UI 참조만 끊는다.

**위계는 굵기와 크기로만** 만든다:
- 헤드라인 600
- 본문 400
- 캡션/키커 500 + `letter-spacing: 0.08em` + 대문자

**히어로 이름을 줄인다**: `clamp(2.6rem, 8vw, 5rem)` → `clamp(2.4rem, 6vw, 3.6rem)`.
절제된 디자인에서는 큰 글씨보다 여백이 격을 만든다.

**숫자 정렬**: 지표(`.stat-value`)에 `font-variant-numeric: tabular-nums` 적용.

### 4. 여백과 형태

- **섹션 여백 약 1.6배 확대** — A 방향의 핵심. 색을 뺀 자리를 여백이 채운다.
- **모서리 반경 축소**: `--radius: 16px → 6px`, `--radius-sm: 10px → 4px`
- **그림자 제거**, 얇은 1px 테두리로 대체: `--shadow: none`
- **hover 부양 효과 제거**: `.btn`, `.project-card`, `.theme-toggle`의 `translateY(-2px)` 삭제.
  hover 시에는 테두리 색과 배경만 미세하게 변경

### 5. 유지하는 동작

기능은 일절 건드리지 않는다:
- 타이핑 애니메이션 (`runTyping`)
- 스크롤 reveal
- 다크/라이트 토글 + `localStorage` 유지
- 프로젝트 상세 모달
- 모바일 햄버거 메뉴 (≤720px)
- `prefers-reduced-motion` 대응
