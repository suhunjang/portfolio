## 보편 원칙 (7가지)

체크리스트로 쓴다 — 화면을 만들거나 리뷰할 때 각 항목을 통과하는지 본다.

### 1. 위계 (Hierarchy)
가장 중요한 것이 가장 먼저 보여야 한다. 크기·굵기·색 대비·여백으로 시선 순서를 **의도적으로** 설계한다.
- 한 화면에 시각적 1순위는 하나만. 전부 강조하면 아무것도 강조되지 않는다.
- {이 프로젝트의 1순위 요소 — 예: "대시보드에서는 현재 상태값"}

### 2. 점진적 공개 (Progressive Disclosure)
한 번에 다 보여주지 않는다. 복잡한 흐름은 단계로 쪼개고 진행 상태를 표시한다.
- 고급 옵션은 기본 접어둔다. 자주 쓰는 것만 펼쳐둔다.
- {이 프로젝트에서 숨길 것 / 단계로 쪼갤 흐름}

### 3. 일관성 (Consistency)
같은 것은 같게 보이고 같게 동작한다. 버튼·간격·용어를 화면마다 바꾸지 않는다.
- 새 패턴을 만들기 전에 기존 패턴을 먼저 찾는다. 학습 비용이 곧 인지 부하다.
- 아래 **컴포넌트** 섹션의 클래스를 복사해 쓰고, 변형이 필요하면 그 섹션을 고친다.

### 4. 대비 (Contrast)
중요한 액션과 부수적 액션을 색으로 구분한다.
- 파괴적 액션(삭제 등)은 다른 색. 주 액션은 하나만 강조.
- {예: "삭제=빨강, 주 액션=흰 배경, 나머지=텍스트 버튼"}

### 5. 접근성 (Accessibility)
- 본문 대비율 **4.5:1 이상**, 큰 텍스트 3:1 이상 (WCAG AA).
- 색만으로 의미를 전달하지 않는다 (색맹 사용자 — 아이콘/라벨 병행).
- 키보드로 모든 인터랙션 가능. 포커스 링을 지우지 않는다.
- 이미지에 alt, 아이콘 버튼에 aria-label.

### 6. 근접성 (Proximity)
관련된 것은 붙이고 관련 없는 것은 띄운다. 그룹 간 간격 > 그룹 내 간격.
- 파괴적 버튼은 자주 쓰는 버튼과 **떨어뜨린다** (오클릭 방지).

### 7. 정렬 (Alignment)
일관된 그리드에 맞춘다. 정렬선이 어긋나면 이유 없이 지저분해 보인다.
- {예: "좌측 정렬 기준선 하나. 중앙 정렬은 빈 상태(empty state)에만"}

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |

## 색상
### 배경
| 용도 | 값 |
|------|------|
| 페이지 | {예: #0a0a0a} |
| 카드 | {예: #141414} |

### 텍스트
대비율은 페이지 배경 기준. 본문은 4.5:1 이상이어야 한다(원칙 5).

| 용도 | 값 | 대비율 |
|------|------|------|
| 주 텍스트 | {예: text-white} | {예: 19.3:1} |
| 본문 | {예: text-neutral-300} | {예: 11.2:1} |
| 보조 | {예: text-neutral-400} | {예: 7.4:1} |
| 비활성 | {예: text-neutral-500} | {예: 4.6:1} |

### 데이터/시맨틱 색상
| 용도 | 값 |
|------|------|
| {긍정/성공} | {예: #22c55e} |
| {부정/에러} | {예: #ef4444} |
| {중립/기본} | {예: #525252} |

## 컴포넌트
### 카드
```
{예: rounded-lg bg-[#141414] border border-neutral-800 p-6}
```

### 버튼
주 액션은 화면당 하나만 강조한다(원칙 1·4). 파괴적 액션은 다른 색 + 다른 위치(원칙 6).

```
Primary:     {예: rounded-lg bg-white text-black hover:bg-neutral-200}
Secondary:   {예: rounded-lg border border-neutral-700 text-neutral-200}
Destructive: {예: rounded-lg bg-red-600 text-white}
Text:        {예: text-neutral-500 hover:text-neutral-300}
```

포커스: {예: focus-visible:outline focus-visible:outline-2 focus-visible:outline-white} — 지우지 않는다(원칙 5).

### 입력 필드
```
{예: rounded-lg bg-neutral-900 border border-neutral-800 px-4 py-3}
```

## 레이아웃
- 전체 너비: {예: max-w-5xl}
- 정렬: {예: 좌측 정렬 기본. 중앙 정렬 금지} (원칙 7)
- 간격: {예: gap-3~4, 섹션 간 space-y-8}
- **그룹 간 간격 > 그룹 내 간격** (원칙 6). {예: 그룹 내 gap-3, 그룹 간 gap-8}
